# O que é RAG

RAG significa Retrieval-Augmented Generation, em português "geração aumentada por busca". É uma técnica que ajuda um modelo de IA a responder usando os seus próprios documentos.

O RAG tem três passos. Primeiro, os documentos são divididos em trechos pequenos. Segundo, quando chega uma pergunta, o sistema procura os trechos mais parecidos com ela. Terceiro, esses trechos são enviados ao modelo junto com a pergunta, e o modelo escreve a resposta.

O RAG ajuda a reduzir respostas inventadas, porque o modelo recebe o texto certo para ler. Também permite usar informações novas ou privadas sem treinar o modelo de novo.
