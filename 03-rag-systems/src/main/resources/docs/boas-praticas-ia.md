# Boas práticas com IA

Nunca coloque a chave de API no código nem no GitHub. Use variáveis de ambiente.

Chamar um modelo de IA custa dinheiro por uso. Por isso, os testes automáticos devem usar o modo simulado, que não gasta nada.

Uma aplicação pública precisa de login e de limite de uso. Sem isso, qualquer pessoa pode gastar os créditos da sua chave.

Sempre mostre de onde a resposta veio. Mostrar as fontes ajuda o usuário a confiar na resposta e a conferir se ela está certa.
